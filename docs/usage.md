# الاستخدام والحصص (Davinci، المرحلة B)

- **الوحدات:** `text` (نصوص بالذكاء الاصطناعي)، `voice_sec` (ثواني صوت، تقدير 2.3 كلمة بالثانية)، `image` (محجوزة للاستوديو).
- **التسجيل:** `usage_daily` صف لكل شركة/يوم/موديول/وحدة، يزيد عن طريق `usage_add()` (migration 024). اليوم والشهر بتوقيت الرياض.
- **الحد:** `usage_quotas`. بدون صف = بلا حد. لو الاستهلاك + الطلب أكبر من الحد يرجع 429 برسالة عربية، والباقي يشتغل.
- **يتسجل من:** الكوبي رايتر، التصميم، الامتثال (إعادة الصياغة)، السوشال (اقتراح)، الرحلات (كتابة)، الصوت (إعادة كتابة، وتوليد الصوت). يتسجل بس لو الذكاء الاصطناعي مفعّل.
- **ما يكسر شي:** لو migration 024 ما انطبق أو Supabase وقع، الفحص والتسجيل يتجاهلون الخطأ والميزة تكمل.
- **الواجهة:** الإعدادات ← الاستخدام (للمالكة): الاستهلاك لكل موديول، وتحديد الحد. API: `GET/PATCH /api/admin/usage`.
